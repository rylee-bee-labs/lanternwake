# Kenney art in this pack

All third-party art in LANTERNWAKE comes from Kenney.nl asset
packs (CC0 1.0). Sources are the estate library copies of
Kenney Game Assets All-in-1 3.7.0.

| Pack | Used for |
|---|---|
| Tiny Dungeon | people, monsters, items, dungeon tiles |
| Tiny Farm | fields, trees, props |
| Tiny Ski | snow, ice, pines, cabin walls |
| Tiny Town | sea, grass, cobbles |

Processing (this folder's `../../art/tools/build_art.py`): nearest-
neighbour upscale, hue-shifted villager variants (skin tones
spared), a composited title. Every source tile was identified by
looking; the identifications are recorded in design/ART.md.

Credit (appreciated, not required): Kenney - www.kenney.nl
